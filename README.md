# The One-Line Cat Joke That Lands

One original one-line cat joke, written for the make.fun competition
[u-aldy998-the-one-line-cat-joke-that-lands-a7b18262](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

The program copies `entry.txt` to `/output/entry.txt`. The joke:

> I bought my cat a $90 bed. He sleeps in the box it came in — on top of the receipt, so I never forget what a fool I am.
